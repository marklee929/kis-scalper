# System Invariants (절대 규칙)

아래 규칙이 깨지면
시스템은 더 이상 신뢰할 수 없다.

1. 상태 변경 단일성
- 계좌/포지션 상태는 event_loop에서만 변경

2. 전략 무권한
- Entity는 주문을 직접 실행할 수 없다

3. 장중 학습 금지
- Runtime 중 파라미터 변경 금지

4. 로그 선행
- 로그 없는 행동은 불법

5. 환경 우선
- API 장애 = 환경 재난
- 전략 판단보다 리스크 차단이 우선

6. 삭제 금지
- 전략/세대는 삭제하지 않고 봉인

7. 인간 개입 최종권
- 멸망 트리거 이후 재개는 인간 승인 필요

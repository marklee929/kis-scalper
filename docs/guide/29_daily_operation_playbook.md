# Daily Operation Playbook

## 장 시작 전 (T-30 ~ T-5)
- [ ] 시스템 상태 확인
  - API 연결
  - WS heartbeat
  - 잔고/포지션 일관성
- [ ] 멸망 트리거 해제 여부 확인
- [ ] 전일 봉인/동면 목록 확인 (조치 없음)

## 장중
- ❌ 개입 금지
- ❌ 전략 변경 금지
- ⭕ 대시보드 관찰만 허용

관찰 포인트:
- 레짐 급변
- 사망 이벤트 연속 발생
- API 지연 증가
- News severity 급상승

※ 관찰은 기록이지 행동이 아니다.

## 장 종료 직후
- [ ] 시스템 정상 종료 확인
- [ ] 로그 무결성 확인
- [ ] 자동 스코어링 실행 여부 확인
- [ ] 진화 결과 요약 리포트 확인

인간은 승인만 한다.
수정은 하지 않는다.

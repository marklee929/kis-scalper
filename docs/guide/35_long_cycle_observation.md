# Long Cycle Observation (장기 관측 가이드)

이 시스템은
일 단위로 평가하지 않는다.

## 관측 주기
- 주간: 안정성 / 사망 빈도
- 월간: 레짐 적응 / 패러다임 적합성
- 분기: 세대 교체 / 동면 재등장
- 연간: 환경 가정 유효성

## 중요한 질문
- 무엇이 살아남았는가?
- 무엇이 반복적으로 죽는가?
- 환경이 바뀌었는가, 개체가 약한가?

## 경고 신호
- 모든 세대가 동시에 부진
- risk_off 상태가 상시화
- 멸망 트리거 빈도 증가

이 경우:
- 전략 수정 ❌
- **환경 가정 재검토 ⭕**
